# 🗺️ Gerenciador de Rotas e Distâncias entre Cidades

Projeto acadêmico desenvolvido em **C++** com o objetivo de gerenciar o cadastro de cidades, armazenar e consultar distâncias utilizando matrizes, e calcular trajetos personalizados via console.

## 🚀 Sobre o Projeto
O sistema funciona através de um menu interativo completo que valida as entradas do usuário, garantindo a integridade dos dados inseridos (como tratamento de strings, números inteiros e valores decimais para as distâncias). O programa permite calcular rotas encadeadas entre várias cidades e soma automaticamente a distância total percorrida.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** C++
* **Conceitos aplicados:** * Manipulação de Matrizes e Vetores
  * Funções modulares
  * Validação rigorosa de dados de entrada (`string`, `int`, `float`)
  * Estruturas de repetição e controle (`do-while`, `switch-case`)

## ⚙️ Funcionalidades do Sistema
1. **Definição da Quantidade de Cidades:** Define o limite de cidades a serem utilizadas (com limite máximo de 20).
2. **Cadastro de Nomes:** Insere os nomes das cidades com validação alfabética.
3. **Registro de Distâncias:** Cadastra a distância em quilômetros entre os municípios (formando uma matriz simétrica).
4. **Listagem de Cidades e Matriz:** Exibe visualmente os nomes e a matriz completa de distâncias cadastradas.
5. **Consulta de Distância:** Mostra a distância exata entre duas cidades vizinhas.
6. **Criação de Trajeto:** Permite montar uma viagem passando por várias cidades em sequência, validando se há conexão entre elas e calculando a **distância total do trajeto**.
7. **Limpeza de Tela e Encerramento:** Comandos utilitários para melhor experiência no console.
